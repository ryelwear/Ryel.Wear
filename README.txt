RYEL WEAR WEBSITE — FINAL PACKAGE

Upload index.html and the complete images folder to the ROOT of your GitHub Pages repository (not inside an extra nested folder). Keep the social links and payment instructions in the page.

GOOGLE SHEETS: Open the spreadsheet that is linked to your Apps Script, Extensions > Apps Script. Replace Code.gs contents with Apps_Script_Code.gs, Save, then Deploy > Manage deployments > Edit > New version > Deploy. Use this web app URL in the website: 
https://script.google.com/macros/s/AKfycbxmCXS-l3K9VhfqEUe_FLukIZHq3Ko-b4PXxKTUGrbwYKENYeFWSX1dpMCwK64waIDX/exec

Important: Apps Script must be deployed as Web app with Execute as: Me and access allowed to Anyone. Approve permissions. The website uses no-cors POST, so browser cannot read the server response; place a small test order and verify the new row appears in the Sheet. Do not submit real customer details during testing.

Image assets are in /images and must be uploaded together with index.html.
