RYEL WEAR — FINAL WEBSITE PACKAGE

IMPORTANT: Do not upload this ZIP file itself as the website page.

1. Open this ZIP and extract index.html.
2. In your existing GitHub Pages repository, upload/replace index.html at the repository ROOT (same level as README.md, not inside a folder).
3. Commit the change. Keep only one root index.html.
4. Wait a minute, then refresh your published GitHub Pages URL. If it still shows 404, check Repository Settings > Pages and make sure the correct branch and /(root) folder are selected.
